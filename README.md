# SceneSketch

Repository for **SceneSketch: Compact Semantic Communication via Dual-Stream Representation and Executable Interpretation for Traffic Reasoning**.

## Overview

SceneSketch is a framework for compact, task-oriented visual semantic communication for traffic reasoning. It combines two complementary streams derived from shared sparse visual observations: concise task-conditioned descriptions and hierarchically structured semantic representations. Under a communication byte budget, the structured stream preserves the dependencies needed for deterministic receiver-side interpretation. An executor recovers typed results and support statuses, including abstention, which a frozen reasoner combines with the description stream to answer traffic reasoning questions.
